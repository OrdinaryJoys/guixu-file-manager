# 归序桌面端

这是 Tauri 2 桌面入口，已连接原生目录选择、后台索引、文件分页、FTS5 搜索、安全预览、智能文件夹、任务中心、选择式整理预览、持久操作历史、安全撤销和只读精确重复分析。现有 Python 版本继续作为旧功能和安全回归基准。

```bash
cargo test --workspace
cargo check --workspace
cargo run -p guixu-desktop
```

桌面前端不得直接访问任意文件系统路径。目录授权、预览和操作均通过具有明确权限范围的 Rust 命令提供。

整理操作必须由用户勾选文件后生成 15 分钟有效的预览计划。执行前会重新验证全部文件身份、快照和目标冲突；操作意图持久化成功后才开始移动。应用启动时仅对中断操作做只读身份审计，歧义状态不会自动移动或删除文件。

重复文件页当前只提供精确内容分析和建议保留路径。它不会自动选择或删除任何文件；清理执行器将在隔离区/系统废纸篓与可恢复日志完成后单独开放。
