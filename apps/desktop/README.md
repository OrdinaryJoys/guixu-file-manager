# 归序桌面端

这是 Tauri 2 桌面入口，已连接原生目录选择、后台索引、文件分页、FTS5 搜索、安全预览、智能文件夹、任务中心、持久化设置、选择式整理预览、持久操作历史、安全撤销和只读精确重复分析。现有 Python 版本继续作为旧功能和安全回归基准。

M4 通用文件操作已经完整接入：批量重命名、安全复制、通用移动与可恢复删除共享计划、日志、执行和撤销状态机。可恢复删除使用资料库内部 `.guixu-trash` 受控隔离区；索引和监听会排除它，历史记录可恢复原路径，当前不会自动永久清空。

```bash
cargo test --workspace
cargo check --workspace
cargo run -p guixu-desktop
cargo tauri build --debug --bundles app
```

最终 UI 验收必须使用 Tauri 官方生成的 `target/debug/bundle/macos/归序.app`。浏览器 `?demo=1` 只用于快速检查 DOM 和演示数据，不能替代原生 WebKit、capability、系统选择器和真实窗口尺寸验收。

桌面前端不得直接访问任意文件系统路径。目录授权、预览和操作均通过具有明确权限范围的 Rust 命令提供。

整理操作必须由用户勾选文件后生成 15 分钟有效的预览计划。执行前会重新验证全部文件身份、快照和目标冲突；操作意图持久化成功后才开始移动。应用启动时仅对中断操作做只读身份审计，歧义状态不会自动移动或删除文件。

重复文件页使用绑定文件身份、快照和算法版本的持久快速指纹/完整哈希缓存，并显示本次读取量与缓存命中。每个文件展示可解释保留评分；不会默认选择清理项，也不允许选中整组。用户逐项确认后会复用现有可恢复删除计划、执行、历史和撤销链路，不提供永久删除入口。
