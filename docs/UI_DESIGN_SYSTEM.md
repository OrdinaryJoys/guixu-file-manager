# 归序 UI 设计系统

> 状态：v1，适用于桌面主线 Web UI
>
> 目标：让资料库、智能文件夹、重复分析、任务、历史和设置共享同一套视觉语义，新增功能不得自建近似色或独立组件风格。

## 1. 设计原则

1. **安静而可辨识**：内容区使用中性白/灰绿表面，荧光绿只表达主操作、选择和运行状态。
2. **层级来自结构**：画布、面板、卡片、控件四级表面固定，不用随机阴影或深浅变化制造层级。
3. **风险必须显式**：可恢复清理使用危险语义；永久删除在完成独立安全评审前不进入产品。
4. **同类同形**：同层按钮、卡片、弹窗标题栏和状态标签必须共享尺寸、边框、圆角和交互态。
5. **最小窗口可用**：900×620 是桌面验收下限；内容可滚动，主操作、任务状态和关闭入口不可被遮挡。

## 2. 设计令牌

唯一来源为 `apps/desktop/web/app.css` 的 `:root`。新增样式应优先复用以下语义变量：

| 类别 | 令牌 | 用途 |
| --- | --- | --- |
| 文字 | `--color-text` | 标题、主要内容 |
| 文字 | `--color-text-secondary` | 控件文字、次级信息 |
| 文字 | `--color-text-muted` | 描述、路径、标签 |
| 表面 | `--color-canvas` | 应用画布 |
| 表面 | `--color-surface` | 主面板、卡片、弹窗头尾 |
| 表面 | `--color-surface-subtle` | 预览区、表头、任务中心 |
| 表面 | `--color-surface-muted` | 设置导航、悬停态 |
| 边界 | `--color-border` | 控件和卡片标准边框 |
| 边界 | `--color-border-soft` | 面板内部分隔线 |
| 强调 | `--color-accent*` | 主按钮、选中项、运行状态 |
| 成功 | `--color-success*` | 普通通知、完成状态 |
| 危险 | `--color-danger*` | 失败、可恢复清理、错误 |
| 圆角 | `--radius-control/card/panel/modal` | 控件、卡片、主面板、弹窗 |

禁止为了“看起来差不多”新增相邻的灰色、绿色或边框色。确有新语义时，先补充令牌和用途，再使用。

## 3. 公共组件规则

### 按钮

- 主按钮：`.primary-button`，每个视图原则上只有一个主要动作。
- 次按钮：`.quiet-button`，用于取消、刷新、显示、清除选择等可逆动作。
- 风险按钮：`.danger-button`，只用于失败恢复或进入可恢复清理计划。
- 图标按钮：`.icon-button`，必须带 `aria-label`。
- 所有按钮共享焦点环、禁用态、最小高度和悬停反馈；不得用不可点击文字模拟按钮。

### 卡片与面板

- 主内容容器使用 panel 层级和轻阴影。
- 统计、事实、任务、计划、历史和本地数据卡片使用 card 层级，不额外叠加阴影。
- 卡片内通过留白和软分隔线组织内容，不再套第三层卡片。

### 弹窗

- 统一由 `.modal-head`、内容滚动区和 `.modal-actions` 构成。
- 标题栏和操作栏使用白色 surface，中部使用 subtle surface。
- 关闭按钮始终位于右上角；主操作始终位于右下角。
- 错误贴近触发位置显示，不只写入全局通知。

### 状态与选择

- 普通/完成状态使用成功语义，失败/需恢复使用危险语义。
- 选中项使用浅强调色，不使用危险色。
- 重复文件不得默认勾选；每组必须保留至少一项，清理必须进入计划预览。

## 4. 页面结构

- **侧栏**：只承载一级业务导航、智能文件夹列表和固定底部设置入口。
- **工具栏**：资料库身份与唯一主入口“选择文件夹”。
- **资料区**：通知、概览、搜索和文件/预览双栏。
- **任务中心**：固定显示后台工作的真实状态与允许的状态机操作。
- **设置**：通用、外观与显示、扫描与性能、本地数据四个稳定分类；新设置按影响范围归类，不新增孤立弹窗。

## 5. 变更验收门

每次 UI 变更至少验证：

1. 1180×760 标准窗口和 900×620 最小窗口；
2. 主页面、设置、智能文件夹、重复文件、历史和任务状态；
3. 键盘可见焦点、禁用态、悬停态、弹窗关闭与主操作；
4. 浏览器控制台零错误；
5. 新增 CSS 优先使用现有令牌，不复制公共组件规则。
