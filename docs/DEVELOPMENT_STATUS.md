## 最新增量与修复

### 2026-08-03：规模基准、强杀矩阵与生产启动修复

- **原生 E2E 扩至 8 场景**：多文件批量重命名/整理/废纸篓的"计划→执行→历史→撤销"闭环；E2E 暴露并修复 3 个产品 bug（trash 扫描排除丢失、reconcile 刷新竞态、trash 子树对账）。
- **进程级强杀矩阵 3/3**：`fault-injection` feature + `kill_injection` example + 编排脚本；意图日志后强杀收敛 failed（文件未动）、发布后强杀收敛 completed（文件在目标），无"文件已动但状态未知"中间态。
- **规模 fixture 与基准**：固定种子生成器（10k/100k/1m，标准/tiny 分布）；10k 扫描 1.75s、100k 30.5s（扩展 16.8× < 20× 预算）；100k 热搜索最差 87.9ms（< 200ms 预算）；100k 重复分析 9.6s 零假阳性（99.9% 仅需快速指纹）。
- **生产启动阻断修复**：capabilities 缺 `core:default` 导致 `window.__TAURI__.core` 未注入（Tauri 2 按权限裁剪注入），生产启动走前端 demo 分支完全不可用；E2E 因 wdio 插件自动补权掩盖。修复后真实窗口验证库恢复、列表、概览、任务中心正常，并加回归断言。
