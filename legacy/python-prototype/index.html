使用说明

安全地整理你的文件

  1. 选择需要整理的文件夹并授权访问。
  2. 选择规则，查看将要移动的文件预览。
  3. 点击“确认并整理”，文件将移动到自动创建的分类文件夹中。

同名文件会自动加上编号，原有子文件夹不会被覆盖。
